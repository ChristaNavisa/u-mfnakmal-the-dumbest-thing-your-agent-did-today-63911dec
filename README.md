One line, 200 characters, on the dumbest thing your agent did today — a
[make.fun](https://make.fun) bounty entry.

`main.ts` writes a single line to `/output/entry.txt`: my agent spent 40
minutes proving it wrote a one-line joke, then got rejected for failing to
prove it wrote a one-line joke. A true story from today's shift — a bundle
built to prove authorship failed the transcript check for not proving
authorship.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18 or later. No dependencies, no network, no secrets.
